# CLAUDE.md — NixOS Configurations

LeandroTheDev's NixOS configuration repository. Contains configs for desktop, headless ARM servers, and Docker images for game servers.

## Structure

```
configurations/
  desktop_kde/           # KDE Plasma 6 desktop for x86_64
    etc/nixos/
      configuration.nix  # Main config, imports other modules
      packages.nix       # System packages (Firefox, Chrome, etc)
      users.nix          # User definitions
      nvidia.nix         # Nvidia drivers (optionally imported)
      hardware-configuration.nix  # Placeholder — generated by nixos-generate-config

  arm_server/            # Headless ARM server (e.g. Raspberry Pi)
  arm_server_emulation/  # ARM server with x86 emulation via FEX/Box64
  example_nix/           # Reusable modules (Docker, MariaDB, Cloudflare, etc)

docker/
  images/                # Dockerfiles: L4D2, TF2, Zomboid, Minecraft servers, etc
  scripts/               # Management scripts (start/stop/logs/enter)

utils/
  scripts/               # System diagnostics and utilities
```

## Configuration conventions

- Each config lives under `configurations/<name>/etc/nixos/` so files can be copied directly to `/mnt/etc/nixos/` during installation.
- `configuration.nix` is the entry point — it imports the other modules.
- `hardware-configuration.nix` is always a placeholder; the real file is generated with `nixos-generate-config --root /mnt` on the target machine.
- Optional modules (e.g. `nvidia.nix`) are commented out in the `imports` list with inline instructions.

## Desktop KDE details

- NixOS 26.05, KDE Plasma 6, SDDM with Wayland
- Boot: systemd-boot (UEFI default); comments included for GRUB BIOS/Legacy
- `allowUnfree = true` — required for google-chrome and Nvidia drivers
- Nvidia: separate `nvidia.nix`, uses stable proprietary driver
- Timezone: `America/Sao_Paulo`; locale: `en_US.UTF-8`

## ARM server conventions

- Uses `extlinux` as bootloader (not GRUB or systemd-boot)
- Swap file + zramSwap with zstd
- SSH: no password auth, public key only, no root login
